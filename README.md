# GreenDay — доставка здоровой еды

Учебный одностраничный сайт по теме **«Доставка здоровой еды: рационы, цены, заказ»** для Кадырбека Мадияра.

## Ссылки

- Живой сайт: добавьте ссылку после публикации через GitHub Pages.
- Репозиторий: `landing-kadyrbek`.

## Что реализовано

- Семантическая структура HTML5: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Разделы «О нас», «Рационы и цены», «Преимущества» и «Контакты».
- Форма заявки с полями имени, email и сообщения; для каждого поля есть `label` и `required`.
- Иерархия заголовков `h1` → `h2` → `h3`, `alt` у изображения, ссылка пропуска к содержимому и видимый фокус клавиатуры.
- Метаданные `title`, `description`, `viewport`, SVG favicon.
- Адаптивная вёрстка для телефонов от 375 px и широких экранов от 1280 px.

Сайт сделан вручную на HTML5 и CSS3, без шаблонов и конструкторов. Изображение блюда и favicon — собственные SVG-файлы. Цены и контактный адрес демонстрационные. Форма показывает обязательность и корректность полей браузером, но для отправки реальных заявок необходимо подключить обработчик.
