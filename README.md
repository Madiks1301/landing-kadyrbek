# GreenDay — доставка здоровой еды

Учебный одностраничный сайт по теме **«Доставка здоровой еды: рационы, цены, заказ»**. Лабораторная работа №3 выполнена на **Bootstrap 5**.

## Что реализовано
- Bootstrap 5 подключён через CDN: CSS и `bootstrap.bundle.js`.
- Адаптивное меню сделано через `navbar`, `navbar-toggler` и `collapse`.
- Сетка рационов использует `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`.
- Карточки рационов сделаны с компонентом Bootstrap `card`.
- Основные цвета Bootstrap переопределены через CSS-переменные в `:root`, без `!important`.
- Изображения адаптивны, горизонтальной прокрутки нет.

## Почему Bootstrap

Я выбрал Bootstrap, потому что он позволяет быстро делать адаптивную вёрстку с помощью готовой сетки и классов. Особенно удобно использовать `col-12`, `col-md-6` и `col-lg-4`, потому что не нужно вручную писать медиазапросы для каждой карточки. Компонент Navbar помог сделать мобильное меню с кнопкой-бургером без собственного JavaScript. Компонент Card удобно использовать для одинаковых блоков с рационами. При этом Bootstrap иногда мешает, когда нужен полностью уникальный дизайн, потому что стандартные стили приходится переопределять. В отличие от Tailwind, Bootstrap даёт больше готовых компонентов, а в отличие от чистого CSS многие адаптивные решения уже реализованы. Для этого проекта Bootstrap оказался удобным, потому что сайт быстро адаптируется под телефон, планшет и компьютер.
